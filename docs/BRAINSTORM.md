# **Chridle**

> * gioco mobile (magari browser game per semplicità) pensato solo per una persona  
> * idle game rpg, con tantissime build  
> * tema dark, tu sei il guerriero della luce  
> * combatti in idle in continuazione  
> * centinaia di skills, oggetti armi armature ecc. infinite possibilità di build, sinergie  
> * dungeons, raid, torre  
> * sistema di classi  
> * progressione infinita, continua e longeva.  
> * statistiche su statistiche, tantissime statistiche e perk, albero dell abilità  
> * valuta spendibile  
> * grafica semplice, ma deve essere tutto molto soddisfacente. disegni ed assets ben curati, voglio che sia tutto molto bello e figo da vedere.
